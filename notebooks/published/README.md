# Published notebooks

Put here only notebooks ready to version.

- `preprocessing/`: notebooks about preprocessing and feature engineering.
- `modeling/`: notebooks about training, validation, and model analysis.

Suggested workflow:

1. Work in `notebooks/scratch/` during experiments.
2. Move the notebook to `notebooks/published/...` only when it is ready.
3. Add files explicitly (for example `git add notebooks/published/modeling/my_notebook.ipynb`).
